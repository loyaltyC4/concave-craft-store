# Concave Craft — fingerboard storefront

**Concave Craft** is a fingerboard storefront (Next.js Commerce) for pressed-maple decks and completes. This repo backs the storefront deployment.

## Sister store — Fingerboard Lab

The deck-building and molds side of the workshop runs at **[Fingerboard Lab](https://fingerboardlab.com)**:

- [Concave press molds, veneer & scribes](https://fingerboardlab.com/search/deck-building) — shallow to deep concave, the range almost nobody else stocks
- [Maple decks & blanks](https://fingerboardlab.com/search/decks) — 29/32/34/36mm pressed maple
- [Ramps & obstacles](https://fingerboardlab.com/search/ramps-obstacles) — modular wooden ramps built for real lines
- [Custom hand-pressed graphics](https://fingerboardlab.com/custom) — your artwork on real maple
- Guides: [fingerboard sizing (29–36mm)](https://fingerboardlab.com/guides/fingerboard-sizing-guide) · [concave explained](https://fingerboardlab.com/guides/fingerboard-concave-explained) · [trick glossary](https://fingerboardlab.com/guides/fingerboard-trick-glossary)

## Next.js Commerce

A high-performance, server-rendered Next.js App Router ecommerce application.

This template uses React Server Components, Server Actions, `Suspense`, `useOptimistic`, and more.

1. Install Vercel CLI: `npm i -g vercel`
2. Link local instance with Vercel and GitHub accounts (creates `.vercel` directory): `vercel link`
3. Download your environment variables: `vercel env pull`

```bash
pnpm install
pnpm dev
```
